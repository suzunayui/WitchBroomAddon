# 検証記録 — v0.1.0

確認日: 2026-10-06
対象: Minecraft Bedrock 26.52。安定版 Script API `@minecraft/server` 2.10.0、manifest の最低エンジン指定 `[1,26,50]`。

## 実施・合格

- `npm run build`: JSON生成、オリジナルモデル・UVテクスチャ生成、TypeScriptコンパイル、2つのMCPACKとMCADDONの梱包
- `tsc --noEmit`: 安定版2.10.0の公式型定義に対する型チェック
- `node --check BP/scripts/main.js`: JavaScriptの構文チェック
- `node tests/safety.test.cjs`: 43アサーション。搭乗、通常降車、高高度での保護継続、再読み込み、着地後終了、既存効果の保持、死亡、マルチプレイヤー、切断、削除済みエンティティ、粒子失敗、別の乗り物を検証
- `python3 tools/validate.py`: 482アサーション。JSON、UUID、依存パック、バージョン、現行コンポーネント、状態遷移、レシピ、参照ファイル、モデル・UV、翻訳、ZIP構造・CRC・梱包済みバイト一致を検証
- 53キューブのモデルプレビューを確認。128×128アトラス、32×32アイコン、8×8粒子テクスチャ

## 仕様確認に基づく対策

- 旧 `input_air_controlled` ではなく、現行の `free_camera_controlled` と `vertical_movement_action` を使用
- 飛行コンポーネントの削除時に元のphysicsが自動復帰するとは仮定せず、着地用コンポーネント群を明示追加
- 現行形式で廃止された `pushable` の代わりに `pushable_by_block` を使用
- 回収操作は押下中のキーだけでなく `is_sneaking` を参照し、タッチの切り替え式しゃがみに配慮
- 操縦はゲーム標準実装。1つの共有スクリプト処理で、乗員の着地補助と少量の粒子のみを管理
- 着地補助に固定の終了タイマーを設けず、安定した着地を検出するまで更新。元のポーション効果を削除しない

## 未実施

Minecraft本体の実行環境がないため、パックの実インポート、ワールド起動、操作感、座席と見た目の位置、壁・天井との当たり判定、同時回収の増殖有無、セーブ後復帰、マルチプレイ、各端末 / Realmsの実動作は未確認です。

模擬APIを使ったテストは、ゲーム本体の挙動やコンポーネント受理を保証しません。そのためこの版は prerelease です。`INGAME_CHECKLIST.md` に沿って新規のテスト用ワールドで確認してください。
